牟之记忆法 V4 · AI 在线版

包含：
- 苹果风舒适 UI + 悬浮微交互
- 可爱原创 M 形小精灵 Logo
- 正常 / 日式复古掌机主题
- 掌机主题四角原创像素精灵装饰
- 今日间隔复习：1 / 2 / 4 / 7 / 15 / 30 天
- 中文默认隐藏，点击显示

- “刷掉这个词”音效
- 随机 10 题
- AI 单词教练聊天框
- AI 识别词汇后自动加入词库
- 导入 / 导出 JSON
- 分享词库链接

在线 AI 部署：
1. 将整个文件夹部署到 Vercel。
2. 在 Vercel 项目 Environment Variables 中添加 OPENAI_API_KEY。
3. 可选：添加 OPENAI_MODEL；默认 gpt-5.6-luna。
4. 重新部署后，网页中的 AI 聊天框即可通过 /api/chat 使用服务器端 API，不在浏览器暴露 API Key。

注意：直接双击 index.html 仍然可以使用本地复习/测试/导入导出，但无法调用 /api/chat，因为本地没有服务器函数。
